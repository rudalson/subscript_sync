# 🎬 SubSync Studio (자막 시간 싱크 맞춤 프로그램)

동영상을 시청할 때 **시간이 지날수록 자막이 조금씩 점점 밀리거나 앞서가는 현상**(프레임레이트 비례 오차) 및 **중간 광고/편집으로 인한 어긋남**을 완벽하게 맞추는 웹 기반 로컬 자막 싱크 동기화 프로그램입니다.

---

## ✨ 주요 기능

1. **⚡ 원클릭 자막 정렬 (Auto-Sync)**
   - 영상의 대사 채널만 추출한 뒤 신경망 음성 감지(Silero VAD)로 배경음악·효과음과 실제 대사를 구분합니다.
   - 자막 대사 구간과 발화 구간의 상관관계로 전체 배율(프레임레이트 차이)과 오프셋을 찾고, PAL(25fps) ↔ NTSC(23.976fps) 등 대표 변환 패턴을 자동 판별합니다.
2. **✂️ 구간별 정렬 & 대사별 미세 조정**
   - 다른 릴리스용 자막처럼 오프닝·타이틀·컷 차이로 중간부터 밀리는 지점을 자동으로 찾아 구간마다 따로 보정합니다.
   - 각 대사 시작을 주변 흐름에 맞는 실제 발화 시작 지점에 맞춥니다. (두 기능 모두 자막 정렬 탭에서 켜고 끌 수 있습니다)
3. **🎚️ 빠른 수동 보정**
   - 단축키(Z / X)로 전체 자막을 0.1초씩 당기거나 미루고, FPS 변환 탭에서 표준 프레임레이트 변환 비율을 바로 적용할 수 있습니다.
4. **🔊 오디오 파형 & 자막 대사 타임라인**
   - 오디오 볼륨 파형과 자막 대사 블록을 시각적으로 확인하며 즉시 클릭하여 해당 지점으로 이동할 수 있습니다.
5. **📝 다양한 자막 형식 및 한국어 인코딩 완벽 지원**
   - **SRT, SAMI (.smi), WebVTT (.vtt)** 상호 변환 및 저장 지원
   - 한국어 자막 특유의 깨진 **CP949 / EUC-KR** 인코딩을 자동 감지하여 UTF-8로 깨짐 없이 로드
6. **💾 안전한 내보내기**
   - 기본적으로 원본을 보존하는 `[synced] 파일명.srt` 형태로 저장하며, 원본 덮어쓰기 시 `.original.bak` 자동 백업을 지원합니다.

## 🚀 실행 방법

### 1. 프로그램 실행
터미널에서 아래 명령어를 실행합니다:

```bash
npm start
```

### 2. 브라우저 접속
웹 브라우저를 열고 다음 주소로 접속합니다:
👉 **http://localhost:4200**

## ⌨️ 단축키 안내

| 단축키 | 기능 |
|--------|------|
| **Space** | 영상 재생 / 일시정지 |
| **M** | 음소거 토글 / 복원 |
| **Z** | 자막 싱크 -0.1초 앞당기기 |
| **X** | 자막 싱크 +0.1초 미루기 |
| **← / →** | 영상 1초 뒤로 / 앞으로 이동 |
| **Ctrl + Z** | 실행 취소 (Undo) |
| **Ctrl + Y** | 다시 실행 (Redo) |

---

## 💡 자막 정렬 사용 요령

1. 영상과 자막을 불러온 뒤 **자막 정렬** 탭에서 **[분석 시작]** 을 누릅니다. (영화 1편 기준 첫 분석은 30초가량 걸리고, 이후에는 캐시를 사용합니다)
2. 신뢰도·배율·오프셋과 함께 검출된 분할 지점과 미세 조정 결과를 확인합니다.
3. **[적용]** 을 누른 뒤 재생하면서 확인하고, 전체가 조금씩 이르거나 늦으면 **Z / X** 로 0.1초 단위 보정합니다.
