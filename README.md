# 🎬 SubSync Studio (자막 시간 싱크 맞춤 프로그램)

동영상을 시청할 때 **시간이 지날수록 자막이 조금씩 점점 밀리거나 앞서가는 현상**(프레임레이트 비례 오차) 및 **중간 광고/편집으로 인한 어긋남**을 완벽하게 맞추는 웹 기반 로컬 자막 싱크 동기화 프로그램입니다.

---

## ✨ 주요 기능

1. **📍 2포인트 선형 비례 보정 (Linear Calibration)**
   - 영상의 초반과 후반에서 자막이 맞아야 하는 **두 기준점**만 지정하면, 프로그램이 프레임레이트 속도 차이($\alpha$)와 오프셋($\beta$)을 일차방정식($t' = \alpha \times t + \beta$)으로 계산하여 전체 자막을 일괄 보정합니다.
   - PAL (25fps) ↔ NTSC (23.976fps) 등 대표적인 프레임레이트 변환 패턴을 자동 감지합니다.
2. **⚡ 원클릭 자동 음성 싱크 (AI / VAD Auto-Sync)**
   - FFmpeg로 동영상 오디오의 실제 대사 발화 구간(Voice Activity)을 초고속 추출하고, 자막 대사 시점과의 교차상관(Cross-correlation)을 분석하여 원클릭으로 최적의 싱크를 찾아냅니다.
3. **✂️ 구간 분할 보정 (Segment Sync)**
   - 특정 시점(광고 컷, 삭제 씬 등) 이후에만 싱크가 어긋나는 경우, 선택한 자막부터 끝까지만 독립적으로 오프셋을 조절할 수 있습니다.
4. **🔊 오디오 파형 & 자막 대사 타임라인**
   - 오디오 볼륨 파형과 자막 대사 블록을 시각적으로 확인하며 즉시 클릭하여 해당 지점으로 이동할 수 있습니다.
5. **📝 다양한 자막 형식 및 한국어 인코딩 완벽 지원**
   - **SRT, SAMI (.smi), WebVTT (.vtt)** 상호 변환 및 저장 지원
   - 한국어 자막 특유의 깨진 **CP949 / EUC-KR** 인코딩을 자동 감지하여 UTF-8로 깨짐 없이 로드
6. **💾 안전한 내보내기**
   - 기본적으로 원본을 보존하는 `[synced] 파일명.srt` 형태로 저장하며, 원본 덮어쓰기 시 `.original.bak` 자동 백업을 지원합니다.

## 🚀 실행 방법

### 1. 프로그램 실행
터미널에서 아래 명령어를 실행합니다:

```bash
npm start
```

### 2. 브라우저 접속
웹 브라우저를 열고 다음 주소로 접속합니다:
👉 **http://localhost:4200**

## 💡 점진적으로 자막이 어긋나는 이유와 2포인트 보정 요령

동영상과 자막 제작 시 사용된 **초당 프레임 수(FPS)**가 다를 때(예: 25fps 자막을 23.976fps 영상에 적용 시) 시간이 지날수록 오차가 누적됩니다.

- **요령**: 
  1. 영상 **시작 1~5분 부근**에서 배우의 첫 대사가 나오는 곳에 일시정지하고, 자막 목록의 해당 대사에서 **[P1]** 버튼을 누릅니다.
  2. 영상 **후반부(30분~1시간 이후)**에서 대사가 나오는 곳으로 이동해 일시정지하고, 자막 목록의 해당 대사에서 **[P2]** 버튼을 누릅니다.
  3. 우측에 계산된 배율을 확인하고 **[🚀 2포인트 싱크 적용]** 버튼을 누르면 전체 영화의 모든 대사 싱크가 정확하게 맞춰집니다!
